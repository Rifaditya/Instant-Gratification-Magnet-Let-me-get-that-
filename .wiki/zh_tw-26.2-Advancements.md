## 📖 零進度原則與設計範疇

嚴格恪守**即時滿足（Instant Gratification, IG）**模組設計哲學，**Magnet, Let me get that!** 刻意**不包含任何自訂進度樹（Advancements）或里程碑成就**。

本模組被設計為對玩家核心生存互動的內在生活品質（QoL）增強。各項能力在玩家踏入世界的第一秒起便全面解鎖，不存在任何刻意的人為任務刷取、科技樹解鎖或進度阻隔。

```
+-----------------------------------------------------------------------------------+
|                            即時滿足模組核心設計信條                               |
|                                                                                   |
|  「『恥辱之行』（挖掘方塊後還要走 5 格距離去撿起掉落物）是打斷心流狀態的原罪。    |
|    IG 磁吸不是科技樹物品，也不是解鎖獎勵；它是玩家意志的直接延伸。                |
|    只要你能看見它，它就應該屬於你。」                                             |
```

## 🎮 原版原生進度相容性

由於標準牽引飛行模式與[[⚡ 瞬間拾取模式|zh_tw-26.2-Instant-Pickup-Mode]]皆完全複用 Minecraft 原生 `ItemEntity.playerTouch()` 與 `ExperienceOrb.playerTouch()` 收集管道：

1. **原版里程碑進度正常觸發**：透過磁吸拾取鑽石、遠古遺骸或烈焰棒時，會立即觸發原版成就標準（例如「鑽石！」、「用殘骸包裹我」）。
2. **第三方任務模組相容性**：追蹤玩家背包物品拾取的任務模組（例如 FTB Quests 或 Better Questing）完全開箱即用，無需任何額外的相容補丁。
3. **統計數據精確累加**：原版物品拾取統計數據（`stat.pickup.minecraft.*`）保持正常遞增。

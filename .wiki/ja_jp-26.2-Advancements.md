## 📖 進捗の非採用ポリシーと設計範囲

**Instant Gratification（IG）** のモッディング哲学を厳格に遵守するため、**Magnet, Let me get that!** には **カスタム進捗ツリーやマイルストーン実績が意図的に存在しません**。

本 MOD は、プレイヤーの基本的なサバイバル体験を快適にする内因的な QoL 拡張として設計されています。プレイヤーがワールドに降り立ったその瞬間から全機能が解放されており、不条理なクエスト周回、研究ツリー、進行妨害などの障壁は一切設けられていません。

```
+-----------------------------------------------------------------------------------+
|                        INSTANT GRATIFICATION DESIGN TENET                         |
|                                                                                   |
|  「屈辱の歩行（掘ったばかりのブロックを拾うためだけに 5 ブロック歩くこと）は、      |
|    ゲームプレイの集中を乱す大罪である。IG Magnet は技術ツリーのアイテムでも報酬でも   |
|    ない。プレイヤーの意志の延長である。見えているなら、その手にあるべきだ。」         |
+-----------------------------------------------------------------------------------+
```

## 🎮 ネイティブバニラ進捗との完全互換性

標準のバキューム飛行および [[インスタント回収モード|ja_jp-26.2-Instant-Pickup-Mode]] の両方が、Minecraft ネイティブの `ItemEntity.playerTouch()` および `ExperienceOrb.playerTouch()` 回収パイプラインを利用しているため：

1. **バニラマイルストーンの発火**: 磁力によってダイヤモンド、古代の残骸、ブレイズロッドなどを拾い上げた際、バニラの進捗条件（例: 「ダイヤモンド！」、「瓦礫で覆って」など）が即座に正常達成されます。
2. **外部クエスト MOD との親和性**: プレイヤーインベントリ内のアイテム取得を追跡するクエスト MOD（FTB Quests、Better Questing 等）は、専用の互換コードを必要とせずそのまま完璧に動作します。
3. **統計データの追跡**: バニラの統計情報（`stat.pickup.minecraft.*`）も正確にカウントアップされ続けます。

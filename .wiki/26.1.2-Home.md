## ⚡ Key Feature Highlights

* **360° Spherical Line-of-Sight Checks**: Powered by DasikLibrary 1.8.23's `PlayerVisionTracker`. See [[26.1.2-Line-of-Sight-and-Obstruction]].
* **Phase-Shift NoClip Physics**: Items phase through solid terrain during vacuum pull. See [[26.1.2-Vacuum-and-Phase-Shifting]].
* **Instant Pickup Mode**: Optional bounding box expansion for 0-latency collection. See [[26.1.2-Instant-Pickup-Mode]].
* **Concurrent Session Toggles**: Keybind and command state managed via `MagnetPlayerState`. See [[26.1.2-Player-Toggle-and-Persistence]].
* **Cloth Config GUI**: Clean in-game settings screen with category warning notices. See [[26.1.2-Configuration]].

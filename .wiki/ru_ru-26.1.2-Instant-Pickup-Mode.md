## 📖 Обзор мгновенного подбора

В Minecraft 26.1.2 **Режим мгновенного подбора** устраняет время полета предметов за счет расширения хитбокса сбора игрока в методе `Player.aiStep()`, мгновенно отправляя дроп в инвентарь через ванильные обработчики.

```
+-----------------------------------------------------------------------------------+
|                            ВАНИЛЬНЫЙ ТИК ИГРОКА aiStep()                          |
+-----------------------------------------------------------------------------------+
                                          |
                                          v
                +---------------------------------------------------+
                |   PlayerMixin.ig_magnet$expandPickupArea()        |
                |   pickupArea = pickupArea.inflate(range);         |
                +---------------------------------------------------+
                                          |
                                          v
+-----------------------------------------------------------------------------------+
|               ВАНИЛЬНОЕ ВЫПОЛНЕНИЕ ItemEntity.playerTouch(Player)                 |
|   - Ванильное объединение стаков и частичный подбор                               |
|   - Ванильные звуки и анимации сбора (item.pickup / entity.experience_orb)        |
|   - Корректные триггеры статистики и достижений                                   |
|   - Полная обработка переполнения инвентаря и сохранение остатка                  |
+-----------------------------------------------------------------------------------+
```

## 🧩 Архитектурная реализация (`PlayerMixin.java`)

```java
@ModifyVariable(
        method = "aiStep",
        at = @At(value = "STORE"),
        ordinal = 0
)
private AABB ig_magnet$expandPickupArea(AABB pickupArea) {
    Player player = (Player) (Object) this;
    Level level = player.level();
    
    if (!level.isClientSide()) {
        if (ModGameRules.getBoolean(level, ModGameRules.MAGNET_INSTANT)) {
            int range = ModGameRules.getInt(level, ModGameRules.MAGNET_RANGE);
            if (range > 0) {
                return pickupArea.inflate(range);
            }
        }
    }
    
    return pickupArea;
}
```

## ⚙️ Связанные настройки и игровые правила (GameRules)

| GameRule | Тип | По умолчанию | Описание |
| :--- | :---: | :---: | :--- |
| `ig:magnet_instant` | Boolean | `false` | Если true, предметы мгновенно телепортируются в инвентарь вместо полета. |
| `ig:magnet_range` | Integer | `12` | Радиус в блоках для расширенной области подбора. |
| `ig:magnet_enabled` | Boolean | `true` | Главный переключатель всего мода. |

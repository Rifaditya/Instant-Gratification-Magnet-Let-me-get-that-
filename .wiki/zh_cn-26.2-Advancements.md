## 📖 缺失策略与设计范围说明

严格遵循**即时满足（Instant Gratification, IG）**的模组设计哲学，**Magnet, Let me get that!** 刻意**不包含任何自定义进度树或里程碑成就**。

本模组被设计为对玩家核心生存交互的内生体验优化。从玩家进入世界的第一秒起，功能即刻生效，绝无人为的刷任务要求、科技树限制或升级障碍。

```
+-----------------------------------------------------------------------------------+
|                            即时满足 (IG) 核心设计准则                             |
|                                                                                   |
|  “‘耻辱之行’（亲自走 5 格去捡起刚挖下的方块）是对游戏沉浸心流状态的极大破坏。   |
|   IG Magnet 不是科技树节点，也不是任务奖励；它是玩家生存意志的自然延伸。         |
|   只要你目光所及，你就应当立刻拥有。”                                             |
+-----------------------------------------------------------------------------------+
```

## 🎮 原版成就进度完美兼容

由于标准吸附飞行与[[瞬间拾取模式|zh_cn-26.2-Instant-Pickup-Mode]]均直接调用 Minecraft 原生的 `ItemEntity.playerTouch()` 与 `ExperienceOrb.playerTouch()` 收集逻辑：

1. **原版里程碑成就触发**：通过磁铁吸附钻石、远古残骸或烈焰棒等物品时，会立即且正常地触发原版成就判定（例如“钻石！”、“用残骸包裹我”等）。
2. **第三方任务模组兼容性**：用于检测玩家背包物品拾取的第三方任务系统（如 FTB Quests 或 Better Questing）完全开箱即用，无需任何特殊兼容代码。
3. **统计数据追踪**：原版的物品拾取统计数据（`stat.pickup.minecraft.*`）将持续精准累加。

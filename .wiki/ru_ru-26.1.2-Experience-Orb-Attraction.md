## 📖 Механика вакуума сфер опыта

В философии Instant Gratification оставлять сферы опыта без присмотра противоречит комфортному игровому процессу. В Minecraft 26.1.2 сущности `ExperienceOrb` притягиваются с точно такой же скоростью и физикой фазового сдвига, как и выброшенные предметы.

```
+------------------+     getEntitiesOfClass     +-----------------------+     MagnetMovement.pull     +--------------------+
| Область AABB     | -------------------------> | Список ExperienceOrb  | --------------------------> | Сбор игроком       |
+------------------+                            +-----------------------+                             +--------------------+
                                                             |
                                                             v
                                                [Применить фазовый сдвиг]
                                                [Применить вектор Lerp]
                                                [Ограниченные искры частиц]
```

## ⚡ Синхронизированная физика и фазовый сдвиг

1. **Фазовый сдвиг (NoClip)**: Сферы опыта проходят сквозь твердые блоки, что предотвращает их застревание за стенами или в углах потолка.
2. **Интерполяция скорости**: Сферы плавно ускоряются по направлению к глазам игрока с учетом настроенных процентов скорости и ускорения.
3. **Фильтрация видимости (LOS)**: Если параметр `ig:magnet_los_only` включен, сферы опыта должны быть видны игроку либо обладать активным импульсом намагничивания.

## 🛡️ Защита от лагов и пул частиц

```java
int maxParticleSources = ModGameRules.getInt(player.level(), ModGameRules.MAGNET_MAX_PARTICLE_SOURCES);
int particleSourceCount = 0;

for (ExperienceOrb orb : orbs) {
    boolean shouldSpawnParticles = false;
    if (particleSourceCount < maxParticleSources) {
        shouldSpawnParticles = true;
        particleSourceCount++;
    }
    MagnetMovement.pull(orb, player, shouldSpawnParticles);
}
```

* **Максимум источников частиц**: Только первые $N$ сущностей за тик испускают визуальные шлейфы.
* **Безопасное переключение на клиенте**: В `MagnetMovement.java`, если мир не является `ServerLevel`, частицы корректно направляются через `level.addParticle(...)`.

## ⚙️ Связанные настройки и игровые правила (GameRules)

| GameRule | Тип | По умолчанию | Описание |
| :--- | :---: | :---: | :--- |
| `ig:magnet_affects_xp` | Boolean | `true` | Притягивает ли магнит сферы опыта. |
| `ig:magnet_particles` | Boolean | `true` | Главный переключатель визуальных эффектов частиц. |
| `ig:magnet_particle_count` | Integer | `1` | Количество искр на сущность за тик генерации частиц. |
| `ig:magnet_max_particle_sources` | Integer | `5` | Максимум сущностей, испускающих частицы одновременно. |

## 📖 Обзор системы

Основная механика вакуума в моде **Magnet, Let me get that!** сканирует выпадающие сущности `ItemEntity` в пределах заданного радиуса игрока на каждом серверном тике и плавно притягивает их к уровню глаз с использованием нелинейной интерполяции.

Чтобы предметы не цеплялись за края блоков, выступы руд или кроны деревьев, мод активирует **Фазовый сдвиг (NoClip)**, позволяя летящим предметам беспрепятственно проходить сквозь твердые воксели блоков.

```
+-------------+      Линия обзора OK       +----------------------+      Применена скорость Lerp      +------------------+
| Item Entity | -------------------------> | Вкл NoClip (2 тика)  | --------------------------------> | Глаза игрока     |
+-------------+                            +----------------------+                                   +------------------+
                                                       |
                                                       v
                                            [Отмена выталкивания]
                                            [Игнорирование коллизий]
                                            [Отмена гравитации в блоке]
```

## 🧮 Физика и векторная математика

При притягивании предмета траектория рассчитывается непосредственно в 3D евклидовом пространстве:

### 1. Вектор к цели
Пусть $\vec{p}_{\text{entity}} = (x_e, y_e, z_e)$ — текущая позиция предмета, а $\vec{p}_{\text{eye}} = (x_p, y_p + h_{\text{eye}}, z_p)$ — позиция глаз игрока.
$$\vec{v}_{\text{target}} = \vec{p}_{\text{eye}} - \vec{p}_{\text{entity}}$$
$$\hat{d} = \frac{\vec{v}_{\text{target}}}{\|\vec{v}_{\text{target}}\|} = \frac{\vec{v}_{\text{target}}}{\sqrt{\Delta x^2 + \Delta y^2 + \Delta z^2}}$$

### 2. Желаемая предельная скорость
Вектор целевой скорости масштабирует единичный вектор направления $\hat{d}$ с учетом настроенного параметра скорости:
$$\text{Скаляр скорости } s = \frac{\text{GameRule}(\text{ig:magnet\_speed})}{100.0}$$
$$\vec{u}_{\text{target}} = \hat{d} \times s$$
*При стандартном значении ($80\%$), $s = 0.8\text{ блоков/тик}$. При $20\text{ тиках/с}$ предельная скорость равна $16.0\text{ м/с}$.*

### 3. Нелинейное ускорение (Lerp)
Скорость обновляется линейной интерполяцией (`Vec3.lerp`) на основе коэффициента ускорения $a$:
$$\text{Коэффициент ускорения } a = \frac{\text{GameRule}(\text{ig:magnet\_acceleration})}{100.0}$$
$$\vec{v}_{\text{new}} = \vec{v}_{\text{current}} + (\vec{u}_{\text{target}} - \vec{v}_{\text{current}}) \times a$$

### 4. Устранение трения о землю
Если предмет лежит на поверхности блока (`entity.onGround() == true`), контактное трение мгновенно сбрасывается для предотвращения волочения по полу:
```java
if (entity.onGround()) {
    entity.setOnGround(false);
    entity.setPos(entity.position().add(0, 0.05, 0));
}
```

## 🧱 Фазовый сдвиг (Движок NoClip)

Когда параметр `ig:magnet_noclip` активен, предметам присваивается окно NoClip длительностью в 2 тика:

1. **Активация состояния**: Вызов `((IMagnetEntity) entity).ig_magnet$setMagnetNoClip()` устанавливает `noClipTicks = 2`.
2. **Перехват перемещения (`MixinEntity.java`)**:
   - `move(MoverType, Vec3)`: Инъекция `@Inject(at = @At("HEAD"))` сохраняет `originalNoPhysics` и принудительно устанавливает `entity.noPhysics = true`.
   - `move(MoverType, Vec3)`: Инъекция `@Inject(at = @At("RETURN"))` восстанавливает `entity.noPhysics = originalNoPhysics`.
3. **Отмена выталкивания из блоков**: `@Inject(method = "moveTowardsClosestSpace", at = @At("HEAD"), cancellable = true)` блокирует ванильное выталкивание предметов из геометрии блоков.
4. **Условное отключение гравитации**: `@Inject(method = "applyGravity", at = @At("HEAD"), cancellable = true)` отменяет гравитацию вниз *только* тогда, когда предмет физически пересекает воксель блока (`!level.noCollision(...)`), сохраняя естественную дуговую траекторию в воздухе.

## ⚙️ Связанные настройки и игровые правила (GameRules)

| GameRule | Тип | По умолчанию | Диапазон / Единицы | Описание |
| :--- | :---: | :---: | :---: | :--- |
| `ig:magnet_enabled` | Boolean | `true` | `true/false` | Главный переключатель всей логики вакуума. |
| `ig:magnet_range` | Integer | `12` | `1..64` блоков | Максимальный сферический радиус вакуума. |
| `ig:magnet_speed` | Integer | `80` | `1..1000%` | Процент предельной скорости ($80 = 0.8\text{ б/т}$). |
| `ig:magnet_acceleration` | Integer | `10` | `1..1000%` | Процент ускорения притягивания ($10 = 10\%\text{ lerp/тик}$). |
| `ig:magnet_noclip` | Boolean | `true` | `true/false` | Включает прохождение сквозь блоки при притягивании. |
